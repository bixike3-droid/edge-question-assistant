# 题解侧栏 · Edge 扩展

在网页旁边截题、解题和继续追问。使用自己的 DeepSeek API Key，直接连接官方 API。下载后即可加载，使用扩展不需要 Node.js、Python 或构建命令。

## 安装与更新

1. 从 [最新发布](https://github.com/bixike3-droid/edge-question-assistant/releases/latest) 下载扩展 ZIP 并解压。
2. 在 Edge 打开 `edge://extensions`，开启“开发人员模式”，点击“加载解压缩的扩展”。
3. 选择直接包含 `manifest.json` 的 `edge-question-assistant` 目录。
4. 将“题解侧栏”固定到工具栏，点击图标打开侧栏。
5. 在设置里保存自己的 DeepSeek API Key，可点“检查连接”验证网络与 Key。

更新时将新文件覆盖到**原来加载的目录**，再到 `edge://extensions` 点击“重新加载”。同一扩展的 Key、聊天记录、截图、草稿和模式会保留。换目录、换 Edge 配置文件或换电脑前，请先在设置中下载完整备份；之后可恢复记录，并重新填写 Key。

旧版尚无完整备份入口时，请先在原目录升级到本版，再导出备份并迁移目录。

## 截图与图片

- 默认快捷键 **Alt+Shift+S** 直接进入当前网页框选，侧栏关闭时会先打开。按 Esc 取消；截图完成后自动附图并聚焦输入框。可在设置中修改快捷键，或打开 `edge://extensions/shortcuts`。
- 普通网页在当前页面上拖动选区，松开后才捕获并裁出题目。只截取标签页可见内容，不包含侧栏、工具栏或选框。长页面请先滚动到题目位置。
- 对不能画选框的页面，可在侧栏裁剪可见区域截图；也可直接截取可见整页。在线 PDF、本地 PDF 共用浏览器的标签页截图接口。
- 本地 PDF 如被拒绝，请在扩展详情中开启“允许访问文件 URL”。浏览器受限制页面可能需要在题目页重新按快捷键或点击扩展图标，以授权当前页截图。扩展会给出具体操作提示。
- 支持粘贴图片、拖入文件和一次选择多张文件。支持 PNG、JPEG、WebP、GIF，每次最多 4 张，每张文件最多 20 MB；GIF 使用可解码的静态画面。
- 图片可以逐张移除、全部清空、拖动排序，也能用缩略图下的箭头前后移动。排序就是发送给 AI 的图片顺序。
- 点击缩略图查看大图，支持适应侧栏、原始尺寸、进一步放大、上一张/下一张和保存图片。左右方向键切换，Esc 返回。
- 大图会适当缩小与压缩。透明图片转 JPEG 时铺白底。过小、近乎全黑或空白的截图会提示检查；受保护画面可能不能被正常捕获。

## 提问与回答

- 可以只发截图，也可以补充“求第 3 小题”，或纯文字提问。Enter 发送，Shift+Enter 换行，兼容中文输入法。
- 输入框自动增高，文字和图片草稿随对话保存。切换对话、关闭侧栏后可继续编辑。
- **分步讲解**：给出关键过程和理由。
- **简洁答案**：选择题仅给选项，填空题仅给答案，判断题给判断结果；证明题、解答题和计算题给完成题目所需的最少过程。
- **检查我的答案**：核对自己的作答，指出错误位置或确认正确。未提供作答时，会先请你补充。
- 回答流式显示，支持 Markdown、数学公式、表格和代码。公式支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。
- 每条回答可以复制、停止生成后重试或重新回答。读上面的内容时，新回答不会强制把页面拖到底部，可点“回到最新”。
- 可以修改已发送的提问，再附图或更换模式后重答。**修改和重新回答都会建立新对话，原记录完整保留**；新对话顶部可返回源对话。
- 连续追问会带上相关上下文。请求使用最近 30 条可用消息、最多最近 4 张图片；连续文字追问超过 30 条时，会保留最近一道附图题目的截图作为参考。所有完整历史仍保留在本机。
- 看不清、条件不足或不确定时，会要求补充。解题结果仍可能出错，重要答案需要核对。

## 历史、导出与恢复

- 本地保存多条对话，支持搜索标题与消息、重命名、新建、切换和确认删除。
- 当前对话可导出 Markdown 文字记录，也可导出包含截图和草稿的完整 JSON 备份。
- 设置里可备份全部记录或恢复 JSON。备份保留图片、模式、草稿和编辑状态，**不包含 API Key**。
- 恢复前会检查格式、图片可解码性并显示摘要。相同记录跳过；同编号但内容不同的记录作为副本添加，不覆盖现有记录。确认后批量写入。
- 一次备份/恢复最多 256 MB、1000 个对话。更大的记录可分别备份各个对话。
- 清空全部对话需要确认。请先留好备份；Key 独立保存，不随对话清空。

## 设置与故障提示

- Key 支持保存、隐藏/显示、修改和删除。连接检测验证网络、Key 与模型列表访问，账户余额以 DeepSeek 官方平台为准。
- 无效 Key、额度不足、限流、服务忙、断网、回答中断和超时都有明确提示。中断时保留题目和已收到内容，可以重试。
- 请求响应头最长等待 30 秒，流式数据连续 90 秒没有更新时结束等待；单次解题请求总计最多 5 分钟。
- 可调整阅读字号，并直接打开截图权限设置、快捷键设置和最新版下载页。

## 隐私与实现

Key 保存在当前 Edge 配置文件的本地扩展存储中；对话、图片和草稿保存在本地 IndexedDB。Key 的本地存储不做额外加密，请勿在共享配置文件中保存私人 Key。只有发送问题或检查连接时才从扩展直接请求 `https://api.deepseek.com`，没有中间服务器。

Manifest V3 使用 `sidePanel` 常驻侧栏、`scripting` 临时画选框、`tabs.captureVisibleTab` 捕获标签页。全站点权限用于用户触发的截图与选区；脚本仅记录坐标，不读取题目网页的 DOM。`activeTab` 用于用户主动调用时授权当前页。

KaTeX、Markdown-It 及数学字体随扩展本地打包，运行时不从 CDN 加载。模型生成的原始 HTML 不执行，Markdown 中的远程图片不会自动加载；依赖许可证在 `vendor/` 中。

开发检查与验收范围见 [DEVELOPMENT.md](DEVELOPMENT.md) 和 [ACCEPTANCE.md](ACCEPTANCE.md)。
