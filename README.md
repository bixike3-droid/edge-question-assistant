# 题解侧栏（Microsoft Edge）

无需安装 Node.js 或运行构建命令。这个文件夹就是可加载的扩展。

## 安装

从 GitHub 下载时，可点仓库页面的 **Code → Download ZIP**，解压后选择里面直接包含 `manifest.json` 的目录。

1. 在 Edge 地址栏打开 `edge://extensions`。
2. 打开左侧的“开发人员模式”，点“加载解压缩的扩展”。
3. 选择整个 `edge-question-assistant` 文件夹（其中直接包含 `manifest.json`）。
4. 点击工具栏里的“题解侧栏”图标，侧栏就会打开。建议将图标固定在工具栏，之后一键打开。
5. 在侧栏右上角设置里填入自己的 DeepSeek API Key 并保存。

如果之前已加载旧版，请把新文件覆盖到**原来加载的目录**，在 `edge://extensions` 找到“题解侧栏”并点“重新加载”，然后关闭并重新打开侧栏；本地 Key 和聊天记录会保留。若改用新目录重新加载，Edge 可能把它识别为另一个扩展，原有本地数据不会自动迁移。

## 使用

- 打开题目所在的网页，点“框选题目”，直接在**当前网页**上按住鼠标拖出选区；松开后截图会自动加入侧栏。按 Esc 可以取消。
- Edge 不允许扩展在某些页面（例如内置 PDF 阅读器）上画选框。这时会自动打开侧栏裁剪；也可以点“整屏截图”一步附图。
- 可补一句“求第 3 小题”，按 Enter 发送；Shift+Enter 换行。回答会逐字显示。
- 直接继续输入“第二步再讲讲”即可追问。右上角 `☷` 可以回看旧对话，`＋` 可开新对话。
- 回答完成后会渲染 Markdown 与数学公式，支持 `$...$`、`$$...$$`、`\(...\)`、`\[...\]`。旧对话重新打开时也会重新渲染；生成过程中暂时显示原始文字。
- 截图包含当前标签页**可见区域**，不包含浏览器工具栏和扩展侧栏。长页面先滚动到题目位置。

## 注意

- 本地 PDF 如无法截图，到 `edge://extensions` → 本扩展的“详细信息”打开“允许访问文件 URL”。某些受保护的视频或画面无法被浏览器截图接口正常捕获；扩展会提示近乎全黑的截图。
- DeepSeek API Key 存在当前 Edge 配置文件的扩展本地存储中，对话与图片存在本地 IndexedDB。它们不会上传到自建服务器；发送问题时，必要的对话内容和截图会直接发给 DeepSeek 官方 API。请勿在共享的 Edge 配置文件中保存私人 Key。
- 近 30 条对话消息会作为解题上下文发送，最多携带其中最近的 4 张截图；所有历史消息仍保存在本机，除非你在历史页手动删除对话。
- 需要能连接到 `https://api.deepseek.com`，并有可用的 API 额度。截图解题可能出错，重要答案请自行核对。

## 技术说明

扩展采用 Manifest V3 原生 JavaScript、HTML 和 CSS。使用 `chrome.sidePanel` 常驻侧栏、`chrome.scripting.executeScript` 临时在网页画选框、`chrome.tabs.captureVisibleTab` 在选框移除后截取可见标签页、DeepSeek 官方 `deepseek-flash` 视觉模型的 Chat Completions 流式接口。`<all_urls>` 权限用于截取和临时选区；选区脚本仅记录鼠标坐标，不读取网页 DOM。

公式显示所需的 KaTeX 0.18.7、Markdown-It 15.0.2 及字体均随扩展打包，不会在运行时从 CDN 加载。这两个库的许可证随 `vendor/` 目录提供。
